# WikiClaim 

A research prototype for evaluating how well Wikipedia claims are supported by their cited sources.

## Objectives
- Evaluate Wikipedia claims against their cited sources.
- Record claims, sources, evidence, verdicts, and reasoning.
- Identify supported or not supported.
- Explore challenges in verifying factual claims.

## Features
- Loads claim data from Excel.
- Displays claims, sources, evidence, verdicts, and reasons.
- Filters claims by verdict.
- Displays verification summary counts.
- Provides clickable source links.

## Technologies
- React, JavaScript, and Vite
- SheetJS (`xlsx`)
- Lucide React
- CSS

## Limitations
The application organizes research data but does not automatically verify claims or retrieve source texts. Verdict changes are not permanently saved.

## Future Improvements
- Record article titles and claim categories.
- Document supporting passages from cited sources.
- Save and export evaluations.
- Compare human and AI assessments.
